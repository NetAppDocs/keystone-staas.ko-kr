= Keystone STaaS 스토리지 측정 기준 및 정의
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Keystone STaaS는 스토리지 구독을 측정하고 보고하기 위해 특정 용어를 사용합니다. 이러한 용어를 이해하면 대시보드 데이터와 구독 보고서를 해석하는 데 도움이 됩니다.

[cols="1,3"]
|===
| 용어 | 정의 


| 용량(GiB, TiB, PiB) | 데이터 스토리지 용량은 1024의 거듭제곱을 사용하여 측정합니다. 1 GiB = 1024^3^바이트, 1 TiB = 1024^4^바이트, 1 PiB = 1024^5^바이트입니다. 


| IOPS | IOPS(초당 입출력 작업 수)는 애플리케이션이 초당 요청하는 프로토콜 작업 수를 나타냅니다. IOPS는 Keystone 대시보드의 작업 카운터 차트에 표시됩니다. 


| 가용성 | 가용성은 한 달 동안 발생한 전체 I/O 요청 중 서비스가 성공적으로 응답한 I/O 요청의 비율입니다. 이는 한 달 동안 서비스 경계 지점을 기준으로 측정되며, 계획된 서비스 중단 시간 또는 고객이 제공하는 시설, 네트워크 또는 기타 서비스의 사용 불가 시간은 포함하지 않습니다. 


| 내구성 | 내구성은 고객에 의한 삭제 또는 손상을 제외하고, 데이터의 정확성 손실 없이 접근할 수 있는 데이터의 비율을 나타냅니다. 


| 지연 시간 | 지연 시간은 클라이언트로부터 수신한 I/O 요청을 처리하는 데 걸리는 시간으로, 서비스 경계 지점(스토리지 컨트롤러 I/O 포트)에서 측정됩니다. 
|===
